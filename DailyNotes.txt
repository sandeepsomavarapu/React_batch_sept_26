core concept of  Redux:
==================
Store:
	Central container  holding the application state 
State:
		the plain actual js object which containse actual data inside the store 
Actions
			plain js object with type property
Action creators
			functions that returns an action object
Reducers
				pure js functions that  takes the current  state and  an action  then return new state
